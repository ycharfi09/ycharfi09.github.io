Why Ypsilon Script?

🎯

Type-Safe

Strong static typing catches errors at compile time, not runtime. Write safer code with confidence.

⚡

No Overhead

Compiles directly to efficient C++ code. Zero performance overhead - your code runs as fast as hand-written C++.

🔧

Modern Syntax

Clean, expressive syntax with pattern matching, enums, structs, and classes. No semicolons required.

🤖

Built for Robotics

Event-driven programming with tasks, reactive variables, and signals. Perfect for robotics projects.

📦

Module System

Organize code with a clean module system. Load libraries and create reusable components easily.

🎨

Expressive

Pattern matching, switch expressions, and time literals make your code more readable and maintainable.

Traditional Arduino C++
// Verbose, less structured
const int LED_PIN = 13;
int state = 0;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  switch(state) {
    case 0:
      digitalWrite(LED_PIN, HIGH);
      break;
    case 1:
      digitalWrite(LED_PIN, LOW);
      break;
  }
  delay(1000);
}
Ypsilon Script
# Clean, type-safe, expressive
@main

enum LedState { ON, OFF }

mut LedState state = ON
const int LED_PIN = 13

on start {
    pinMode(LED_PIN, OUTPUT)
}

on loop {
    match state {
        ON => digitalWrite(LED_PIN, HIGH),
        OFF => digitalWrite(LED_PIN, LOW)
    }
    delay(1000)
}

Get Started in Minutes

1

Install

Install via npm or clone from GitHub

npm install -g ypsilon-script
2

Write

Create your first .ys file with clean, modern syntax

@main
on loop { ... }
3

Compile

Compile to C++ and upload to your board

ysc your-file.ys
